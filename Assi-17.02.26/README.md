# Logic Builder

## Assignment
Print numbers `1` to `50` using Fizz/Buzz rules and count each output type using loops and functions.

## Rules
- Print `FizzBuzz` if a number is divisible by both `3` and `5`.
- Print `Fizz` if a number is divisible by `3` only.
- Print `Buzz` if a number is divisible by `5` only.
- Otherwise, print the number itself.

## File
- `logic_builder.py`

## Functions
- `fizz_buzz_value(number)`: Returns `Fizz`, `Buzz`, `FizzBuzz`, or the number as a string.
- `print_fizz_buzz_and_count(start, end)`: Loops through the range, prints values, and tracks counts.
- `main()`: Runs the program for `1` to `50` and prints final counts.

## How To Run
From the project folder:

```powershell
python logic_builder.py
```

## Expected Final Counts (1 to 50)
- `Fizz: 13`
- `Buzz: 7`
- `FizzBuzz: 3`
- `Number: 27`

## Example Ending Output
```text
Counts:
Fizz: 13
Buzz: 7
FizzBuzz: 3
Number: 27
```
